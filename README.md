# 注音動物島

注音動物島是以繁體中文及台灣常用注音設計的兒童學習 PWA，提供注音、認字與聲音練習。介面以觸控操作為目標，不加入廣告或第三方追蹤。

## 開發候選版本

V2.0.0 為開發候選版本，版本識別由 `public/src/version.js` 提供；版本號不代表部署或實機驗收完成。島嶼地圖、學習模式、設施、家長工具、課程待審和資料轉移的實際狀態以程式及最終測試報告為準。原創圖示以 SVG 繪製並在本專案內轉為 PNG，不使用外部圖片來源。

課程路線包含南一《國語首冊》、《國語 1 上》與《國語 3 上》，教材內頁資料尚缺，標示 `WAITING_FOR_SOURCE`。家長新增與匯入的課程資料先進待審區，不自動成為題目。現行審核核心為 15 個國字、14 個詞語及 14 題；歷史大字庫與其差異見 `reports/DICTIONARY_AUDIT.md`，不可逕以歷史筆數認定現行題量。

## 本機資料與備份

學習資料留在裝置：匿名角色與家長字庫使用本機儲存，票券交易使用 IndexedDB，課程待審使用獨立本機鍵。既有角色資料遷移採保留舊紀錄原始位元組的方式；家長執行匯入前應先檢視摘要及差異。匯入確認後僅套用支援的個人進度與本機字庫；券交易與課程資料提供快照匯出，不能宣稱已完整還原。裝置匯出的備份可能含私人資料，請由家長妥善保管，不應提交到公開儲存庫。

系統語音是備援，不等同已提供真人錄音。一般 Safari 分頁及加入主畫面版本可能使用不同儲存空間；兩者資料、離線、觸控與音訊均需要在實際 iPhone、iPad 分別驗收。

## 開發

以 Node.js 執行專案測試，並參考 `package.json` 的腳本與 `tests/`。PWA 靜態資源變動應檢查 manifest 及 Service Worker；導覽回應不可寫入 Cache Storage。現有內建資料、未審核候選、及家長本機字庫是不同資料層，請勿混用或覆蓋。不要加入未授權教材、孩子可識別資料、私密連結或憑證。
